## 🌐 Public RPC Endpoints

Use these for remote access to Ghostnet (wallets, dApps, etc.):

**Recommended for Temple Wallet:**
- **TzBoot.net**: `https://rpc.ghostnet.tzboot.net` ⭐

**Alternatives:**
- **Ecad Labs**: `https://ghostnet.ecadinfra.com`
- **SmartPy**: `https://ghostnet.smartpy.io`
- **TzKT**: `https://rpc.tzkt.io/ghostnet`
- **Teztnets**: `https://ghostnet.teztnets.com`

**Your Local Node:**
- `http://localhost:8732` (only accessible from same machine)

Example usage:
```bash
curl https://rpc.ghostnet.tzboot.net/chains/main/blocks/head
```

### Temple Wallet Configuration

1. Click network dropdown → Select "Ghostnet"
2. Go to Settings ⚙️ → Find "Default RPC"
3. Enter: `https://rpc.ghostnet.tzboot.net`

### Temple Wallet (Recommended)
- Website: https://templewallet.com

- Supports Ledger hardware wallets
- Network: Select "Ghostnet" after installation

- Website: https://ghostnet.kukai.app
- Web-based wallet (no installation needed)
- Supports Ledger hardware wallets
